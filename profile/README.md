# HNPlugins

HNPlugins 是一个面向游戏插件与配套服务的组织，当前主要维护：

- `HNCore`：HN 系列基础能力与统一授权接入层
- `HNMail`：邮件系统插件
- `HNEconomy`：经济系统插件
- `HNAttribute`：属性与战斗相关插件
- `NapcatPlugin`：HN 授权中心 NapCat 插件

## 组织协作原则

- 通用协作规范以组织级文档为准
- 仓库内 `AGENTS.md` / `CONTRIBUTING.md` 只补充该仓库特有规则
- 提交信息必须使用中文标题与中文内容
- 未经明确授权，不允许擅自邀请协助者，也不允许添加 `Co-Authored-By` 或任何 AI 共同提交标记

## 仓库分层约定

- 组织层：统一协作、提交、CI/CD、安全、AI 使用规范
- 仓库层：技术栈、目录结构、领域边界、测试要求、发布细节

## 支持与安全

- 使用与贡献说明：见组织级 `CONTRIBUTING.md`
- 安全问题反馈：见组织级 `SECURITY.md`
- 常规支持：见组织级 `SUPPORT.md`
